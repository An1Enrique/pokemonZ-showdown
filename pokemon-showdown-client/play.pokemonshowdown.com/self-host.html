Guía de Self-Hosting

Monta tu propio servidor privado de Pokémon Z Showdown para jugar con amigos, hacer torneos o Randomlockes aunque el servidor público esté saturado.

Requisitos Opción 1: En tu PC Opción 2: Gratis en Render Opción 3: En un VPS Formatos incluidos Admin y personalización

Requisitos previos

  • Node.js >= 22.18.0 (recomendado Node 22 LTS o superior: nodejs.org)
  • Git (git-scm.com)

Opción 1: Montarlo en tu propio PC (Windows / Linux / macOS)

  1. Clona el repositorio e instala/compila el backend:
git clone https://github.com/An1Enrique/pokemonZ-showdown.git
cd pokemonZ-showdown
npm run build
  1. Arranca el servidor y la web con un único comando:
npm start

Eso ejecuta start.js, arranca el motor de Showdown en 127.0.0.1:8000 y abre el cliente web + proxy WebSocket en http://localhost:8080.

¿Cómo invitar a amigos a tu servidor casero?

  • Túnel rápido sin abrir puertos (recomendado): instala cloudflared y ejecuta en otra terminal mientras corre npm start: 
    cloudflared tunnel --url http://localhost:8080
    Te dará una URL https://...trycloudflare.com lista para pasar por Discord/WhatsApp sin tocar el router.
  • En la misma red Wi-Fi / LAN: tus amigos entran desde http://TU_IP_LOCAL:8080.
  • Abriendo puerto en el router: abre el puerto TCP 8080 hacia la IP local de tu PC.

Opción 2: Gratis en la nube con Render (sin tarjeta)

El proyecto ya incluye render.yaml listo para usar en el plan gratuito de Render:

  1. Haz Fork de An1Enrique/pokemonZ-showdown en tu cuenta de GitHub.
  2. Entra en Render → New + → Blueprint (o Web Service) y conecta tu fork.
  3. Si lo creas manualmente como Web Service (Node), pon esta configuración:
    • Build Command: npm run build
    • Start Command: npm start
    • Plan: Free
    • Environment Variables: NODE_VERSION=22.18.0 y LOW_MEMORY=1
Límites del plan gratuito de Render: si pasa ~15 minutos sin nadie dentro, el servidor entra en reposo y tarda ~30–50 segundos en despertar con la primera visita. Tiene 750 horas al mes y el disco se reinicia en cada deploy.

Opción 3: En un VPS (Ubuntu / Debian) para 24/7

Si quieres tenerlo abierto 24/7 sin reposo ni límite de horas (p. ej. para torneos grandes):

git clone https://github.com/An1Enrique/pokemonZ-showdown.git
cd pokemonZ-showdown
npm run build
LOW_MEMORY=1 PORT=8080 pm2 start start.js --name pokemonz-showdown
pm2 save

Coloca Nginx o Caddy delante con certificado HTTPS haciendo proxy inverso (HTTP + WebSocket) hacia 127.0.0.1:8080. Si tu VPS tiene 2 GB de RAM o más, puedes quitar LOW_MEMORY=1.

Administración y personalización

  • Darte rango administrador (~): crea o edita pokemon-showdown/config/usergroups.csv y añade una línea con tunombre,~.
  • Variables soportadas por start.js: PORT (por defecto 8080), HOST (0.0.0.0), BACKEND_PORT (8000), LOW_MEMORY=1.
  • Si editas formatos o datos de Pokémon Z: tras cambiar pokemon-showdown/config/formats.ts o pokemon-showdown/data/mods/pokemonz/, ejecuta cd pokemon-showdown && node build.
